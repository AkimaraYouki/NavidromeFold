## 0.7 재생·음질 표시
변환 MP3의 길이를 알 수 없는 경우 곡 메타데이터로 타임라인을 보완하고 CBR 탐색을 활성화합니다. 192/320kbps의 시간 진행·90초 탐색·일시정지를 검증했습니다.

설정 > 음질 인디케이터에서 꺼짐 / 인앱 전용 / 다른 앱 사용 중에도 표시를 선택합니다. 마지막 모드는 Android의 다른 앱 위에 표시 권한이 필요합니다. 펀치홀 주변은 검정 바탕과 얇은 음질 색상 링입니다. 일반 화면의 음질 카드에는 밝은 효과를 사용할 수 있습니다. 설정 > 펀치홀 · 아일랜드 조정에서 링 지름과 아일랜드 너비 슬라이더, X/Y 각각 ±3,000dp 숫자 입력 및 미세 이동을 사용할 수 있습니다. 접힌 세로 화면에서 표시합니다. 물리적 기울기는 무시하므로 비스듬히 들거나 평평하게 놓아도 유지됩니다. 화면 자체가 가로·역방향으로 회전하거나 펼쳐지면 숨깁니다. 포맷과 샘플링 레이트 사이에 카메라 여백을 둡니다. 링 / 아일랜드 / 링+아일랜드 모양을 선택할 수 있습니다.

음질 표시는 플레이어가 읽은 현재 입력 스트림 기준이며 DAC 출력이나 비트퍼펙트를 측정하지 않습니다. MP3로 변환된 고해상도 원본은 파란색으로 표시합니다. MQA 디코더/렌더러는 제공하지 않습니다. DSD는 플레이어가 실제 DSD 포맷을 보고한 경우에만 해당 색상을 사용합니다.

잠금화면에는 표준 미디어 컨트롤과 곡 변경 알림을 제공합니다. 알림을 누르면 곡 정보 카드를 엽니다. 표시 여부는 시스템 잠금화면 알림 설정의 영향을 받으며 화면을 강제로 켜거나 잠금을 해제하지 않습니다.

## 0.7.2 화면 문구
탐색은 아이콘만 표시하며 TalkBack 이름과 툴팁을 제공합니다. 앨범 제목은 `ALBUM · 전체 개수` 형식입니다. 전체 수는 별도로 집계하므로 첫 페이지가 60개여도 전체 235개인 서버는 235로 표시합니다. 집계 전에는 제목만 표시합니다. 반복적인 진행·완료 문구는 메인에서 숨기며 오류와 필요한 설정 이름은 유지합니다.

## 0.7.5 앨범 커버 블러
설정 > 앨범 배경 블러에서 0~100% 강도를 선택합니다. 실제 배경 커버의 흐림 정도를 바꾸며 플레이어 뒤 화면이 비치는 투명도 조절은 제거했습니다. 기본값은 60%이고 Android 12 이상에서 동작합니다. 메인 화면은 무채색 배경과 중성 패널로 정리했습니다. 48dp 버튼은 유지합니다.

## 0.7.6.1 모델 제외
사용자 요청으로 GPT-6 계열은 모델 목록에서 제외합니다. 이전에 저장된 GPT-6 모델도 요청 전 차단하고 선택을 해제합니다. 다른 모델로 자동 대체하지 않으며 사용자가 직접 선택합니다.
