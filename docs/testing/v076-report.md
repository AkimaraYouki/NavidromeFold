GPT-6 계열을 모델 선택 목록과 추천 요청에서 제외했습니다. 기존 선택도 요청 전에 해제합니다. assembleDebug / lintDebug 성공. 실제 계정 모델 목록은 로그인 후 확인이 필요합니다.

# NaviFold 0.7.6

2026-10-17

## 변경
- NOW PLAYING 드래그: 불투명한 둥근 시트와 하드웨어 합성 레이어로 블러·커버·컨트롤을 함께 이동합니다. 시트가 표시되는 동안 미니 플레이어를 숨기고 종료 시 복원합니다. 제스처 취소/종료의 리소스 정리도 통합했습니다.
- SONG 아이콘: 전체 곡 목록, 곡명/아티스트/앨범 필터, 표시된 목록 재생. 정렬(곡명/아티스트/앨범/연도)과 갱신은 설정에 있습니다. 500곡씩 끝까지 조회하며 경로 태그가 없어도 표시합니다.
- 설정 > ChatGPT 추천: 시스템 브라우저 OAuth PKCE 로그인, state/nonce 및 RSA 서명·issuer/audience/만료 검증, 계정 모델 조회·선택, 추천 목록 확인 후 재생/대기열 추가.
- 토큰은 Android Keystore AES-GCM으로 암호화해 앱 내부에 저장합니다. API 키나 Codex 로그인 정보를 가져오지 않습니다. 연결 해제 시 원격 세션 해제를 요청합니다.
- 추천 요청은 랜덤 후보 최대 40곡의 제한된 태그와 현재 곡명만 전송합니다. 서버 ID 대신 짧은 번호를 사용하고 모델 응답의 중복/범위/타입을 검증합니다. 음원·서버 주소·인증정보는 전송하지 않습니다. 매 곡마다 API 요청하지 않습니다.

## 검증
- assembleDebug, assembleQa, testDebugUnitTest, lintDebug 성공. 단위 테스트 33개, lint 오류 0개 / 경고 33개.
- 에뮬레이터 접힘·펼침 SONG 705곡, 필터 3곡, 필터 목록 큐 3곡 재생 확인.
- 접힌 화면 3회, 펼친 화면 1회 느린 드래그: 미니 플레이어 숨김/복원, 시트 제거, 인디케이터 분리 0회 확인. 중간 프레임 이미지 확인.
- 추천 파서의 정상 순서·서버 ID 미전송·범위 초과·중복·소수·문자 ID 거절 테스트 추가.
- 실제 ChatGPT 로그인·계정별 모델 접근·유료 플랜 한도·실제 추천 품질은 사용자 계정 로그인 전이라 검증하지 않았습니다. ChatGPT 설정 팝업과 연결 전 모델 조회 차단을 QA에서 확인했습니다.

- 실제 삼성 기기 (삼성 테스트 기기)에 업데이트 설치 성공, versionName 0.7.6 / versionCode 14 확인. 실제 기기의 드래그 잔상·계정 로그인은 사용자 확인이 필요합니다.

## 범위
이번 버전은 ChatGPT 연결과 수동 추천 배치 재생 단계입니다. 자동 추천 큐 보충 및 취향 학습 기반 자동 넘기기는 구현하지 않았습니다. 추천 10곡은 대기열에 추가한 후 일반 재생 흐름으로 이어집니다. 실패 시 기존 큐를 유지합니다. 숫자로 남은 플랜 한도를 보여주는 API는 연결하지 않았으며 사용량은 ChatGPT 설정에서 확인합니다.
