# NaviFold 0.7.5 앨범 커버 블러·무채색 UI

2026-10-17.

## 변경
- 이전의 재생 배경 불투명도 조절을 제거하고 설정 > 앨범 배경 블러로 교체했습니다. 0%는 블러 없음, 100%는 강한 블러이며 기본값은 60%입니다. 배경 커버의 blur radius를 0~72dp로 변경합니다.
- 설정 미리보기는 현재 곡의 실제 앨범 커버를 사용합니다. 변경 중 미리보기와 적용/취소를 제공합니다.
- 플레이어 배경 전체 alpha는 1로 복원했습니다. 재생 화면 뒤로 설정/목록 글자가 비치지 않습니다. 커버에서 생성한 배경만 흐려지며 전경 커버·메타데이터·재생 버튼은 흐리지 않습니다.
- 이전 버전의 잘못된 opacity 설정값은 읽지 않으므로 0%로 저장했더라도 플레이어 배경이 투명하게 남지 않습니다.
- 메인 화면의 파랑·보라 그라데이션을 제거했습니다. 배경은 무채색 검정/회색(밝은 모드는 흰색/회색)이며 패널과 테두리도 중성 색으로 바꿨습니다. 선택 아이콘과 재생 버튼의 포인트 색만 유지합니다.
- 높이 48dp 버튼, 짧은 화면 문구, 접힘 전용 인디케이터와 센서 조건 제거는 유지했습니다.

## 확인
- assembleDebug / assembleQa / testDebugUnitTest / lintDebug 성공. 단위 테스트 27개 통과, lint 오류 0개 및 경고 30개.
- QA에서 실제 배경 커버에 블러 0/50/100% 설정 저장, 효과 해제/활성화, 0/36/72dp radius를 확인했습니다.
- 모든 강도에서 플레이어 배경과 전경 alpha는 1임을 확인했습니다. 앨범 상세 버튼 높이 48dp도 유지했습니다.
- 상세 자료: docs/testing/v075-proof.json. 목록·상세·블러 미리보기·재생 화면은 로컬 235개 앨범 fixture로 확인했습니다. 단색에서는 흐림 차이를 확인할 수 없어 fixture 이미지를 여러 색/경계가 있는 합성 패턴으로 바꿨습니다.

블러는 Android 12(API 31) 이상의 RenderEffect를 사용합니다. 이전 Android에서는 해당 슬라이더를 비활성화하고 지원 버전을 표시합니다. 실제 삼성 기기에서 GPU 성능을 별도 측정한 결과는 아닙니다.

이전 변경은 docs/testing/v074-report.md를 참고하세요. 해당 문서의 불투명도 기능은 이번 버전에서 블러 설정으로 대체했습니다.
