# NaviFold 0.7.7 · SMART DJ

2026-10-17

## 사용
1. Navidrome 서버를 연결합니다.
2. 설정 > ChatGPT 추천 > Continue with ChatGPT에서 연결하고 GPT-6을 제외한 사용 가능한 모델을 선택합니다.
3. 설정 > SMART DJ에서 감상 기록 학습, 자동 큐 보충, 취향 기반 자동 넘기기를 각각 켭니다. 라이브러리 데이터 갱신으로 전체 곡과 앨범 태그를 색인합니다.
4. SMART DJ의 곡·장르·레이블·가수·앨범 검색으로 저장된 정보를 탐색합니다. 현재 곡 더 듣기 / 덜 듣기 / 선호 초기화도 제공합니다.

MusicBrainz 정보 보완은 사용자의 요청으로 기본 ON입니다. SMART DJ에서 끌 수 있습니다. 학습·보충·자동 넘기기는 기본 OFF이며 켜면 동작과 전송 항목을 표시합니다.

## 구현
- SQLite에 전체 음악 태그, 계정별 감상 집계와 최근 이벤트 최대 1,000건을 저장합니다. 서버 주소+계정 해시로 이름 공간을 분리합니다. 비밀번호와 API URL은 DB에 저장하지 않습니다. 단말 내 개인 데이터베이스이며 다른 사용자의 집단 감상 데이터를 수집하지 않습니다.
- search3를 500곡씩 끝까지 조회하고 앨범 메타데이터에서 장르·레이블을 보완합니다. 경로 태그가 없어도 색인합니다. 갱신이 성공한 뒤 사라진 곡을 정리합니다.
- 곡명·가수·앨범·장르·레이블을 검색합니다. 레이블이 없는 음원에 임의 값을 만들지 않습니다.
- 감상 완료, 직접 일찍 넘김, 앱 자동 넘김, 오류, 중립 사건을 구분합니다. 실제 재생 중 흐른 시간만 학습하며 탐색으로 끝까지 이동한 시간을 완주로 계산하지 않습니다.
- 최근 선호·장르·가수·앨범·레이블·연도·태그 BPM을 이용해 후보 최대 40곡을 추립니다. 한 가수로 후보가 쏠리지 않도록 분산합니다. ChatGPT에 큐 마지막 곡과 후보 태그, 최근 감상 최대 8건 요약을 보내 자연스러운 순서를 고르게 합니다.
- 입력은 짧은 후보 번호로 바꿉니다. 결과의 정수 여부·범위·중복을 검증합니다. 음원 파일·서버 주소·비밀번호·파일 경로를 OpenAI에 보내지 않습니다.
- 남은 큐가 3곡 이하일 때 최대 10곡을 끝에 추가합니다. 사용자가 선택한 기존 순서를 유지합니다. 반복/셔플/일시정지 중에는 보충하지 않습니다. 서비스가 소유하므로 화면을 전환하거나 앱을 뒤로 보내도 동작합니다.
- 요청당 큐를 보충하고 매 곡마다 추론하지 않습니다. 자동 요청 최소 2분 간격, 시간당 최대 6회, 실패 시 최대 30분까지 대기 시간을 늘립니다. 실패 시 로컬 추천 사용 설정을 제공하며 상태에 LOCAL을 표시합니다. API 키 과금으로 자동 전환하지 않습니다.
- 계정·모델·설정·수동 큐가 바뀐 뒤 도착한 오래된 결과는 적용하지 않습니다. 중복 곡을 추가하지 않습니다.
- 자동 넘기기는 추천으로 추가된 곡에만 적용합니다. 명시적으로 덜 듣기 표시했거나 완주 없이 3회 이상 일찍 넘긴 곡이 대상입니다. 직접 선택한 곡·앨범과 마지막 한 곡은 건너뛰지 않습니다. 연속 최대 2곡이며 자동 넘김을 직접 스킵으로 학습하지 않습니다.
- MusicBrainz 조회는 앨범명/가수명 일치와 검색 점수 95 이상을 요구합니다. 검색 결과는 특정 판본의 확정 태그가 아니므로 원본 태그를 우선하고 외부 출처를 남깁니다. 추천 배치당 새 앨범 최대 3개, 초당 1회 이하, 30일 캐시를 사용합니다. 외부 조회 실패 시 기존 태그로 계속합니다.
- 서버·계정 감상 데이터 삭제 기능을 제공합니다. 음악 파일은 삭제하지 않습니다.

## 검증
- assembleDebug / assembleQa / testDebugUnitTest / lintDebug 성공. 단위 테스트 45개, lint 오류 0개 / 경고 33개.
- 에뮬레이터 실제 재생: 기존 3곡 큐에 추천 10곡 추가(총 13곡), 중복 0개, 직접 스킵 기록 증가, 직접 선택한 싫어요 곡 보호, 추천 곡 자동 넘김 정확히 2회 후 제한, 일시정지 및 보충 끄기 확인.
- 합성 데이터 705곡의 장르/레이블 검색과 타 계정 데이터 0건 확인. UI에서 레이블 검색 결과 705곡 표시 확인. 자료: docs/testing/v077-smart-proof.json.
- ChatGPT 계정·실제 모델 추론 없이 로컬 대체 경로로 서비스 동작을 검증했습니다. 실제 ChatGPT의 추천 품질·플랜 사용 가능 여부·응답 시간은 로그인 후 확인이 필요합니다.
- MusicBrainz 실제 공개 앨범 조회는 HTTP 503 응답이었습니다. 정상 실서버 보완 결과는 이번에 검증하지 못했습니다.

- 실제 삼성 기기 (삼성 테스트 기기) 업데이트 설치 성공, versionName 0.7.7 / versionCode 16 확인.

## 범위와 한계
텍스트 태그와 개인 감상 기록 기반 추천입니다. 음원 신호 분석·청감 평가·가사 감정 분석 모델은 포함하지 않습니다. 레이블/장르가 부족하거나 처음 사용해 기록이 없으면 추천 근거가 적습니다. 태그가 많고 감상 기록이 쌓일수록 개인화에 사용할 근거가 늘어납니다. Navidrome 비밀번호는 기존과 같이 저장하지 않으므로 프로세스가 종료된 뒤에는 서버를 다시 연결해야 합니다. 큐 결과가 없는 작은 라이브러리는 보충하지 않습니다.
