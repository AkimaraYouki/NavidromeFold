# NaviFold 0.7.2 UI 문구 정리

2026-10-17.

## 변경
- 펼친 화면 탐색 레일과 접힌 화면 하단 탐색의 텍스트 라벨 제거. 아이콘과 선택 상태를 유지하고 TalkBack 이름 및 툴팁을 남겼습니다.
- 화면 제목은 ALBUM / FOLDERS / LIBRARY / SETTINGS. 앨범은 ALBUM · 전체 개수로 표시합니다. 검색·즐겨찾기는 SEARCH / FAVORITES와 해당 범위 개수로 표시합니다.
- 전체 앨범 개수는 페이지별 로딩 개수로 대체하지 않습니다. 500개씩 안정된 이름순 목록을 조회해 ID 중복을 제외하여 별도로 집계합니다. 검색과 즐겨찾기도 해당 범위 전체를 집계합니다. 집계가 불가능하면 숫자를 추정하지 않고 제목만 표시합니다.
- 기존 앨범 목록의 60개 단위 연속 스크롤, 설정을 통한 정렬·커버 크기 선택은 유지했습니다.
- 마지막 앨범까지 불러왔다는 문장, 아래로 스크롤 안내, 재생 준비·동기화 완료 등 일상 상태 문구를 메인 화면에서 숨겼습니다. 오류 안내와 연결 테스트 결과는 유지했습니다.
- 폴더·앨범 상세의 재생, 셔플, 대기열 추가, 즐겨찾기, 뒤로 이동은 아이콘으로 교체했습니다. 즐겨찾기 상태는 색으로 구분합니다.
- 현재 곡 시트는 NOW PLAYING, 원본 포맷은 SOURCE, 메타데이터 창은 INFO, 대기열은 QUEUE로 표시합니다. 정보·대기열 비우기도 아이콘으로 전환하고 중복 대기열 버튼을 제거했습니다.
- 설정은 필요한 항목명과 값은 유지하고 반복적인 설명을 줄였습니다. 카메라 보정에 필요한 위치·각도 안내는 조절창에 유지했습니다.

## 확인

- 기존 단위 테스트 27개 통과. lint 오류 0개, 경고 29개.
- 235개 앨범 / 705곡의 로컬 서버에서 ALBUM · 235 표시 확인.
- 화면에 탐색 텍스트가 없고 각 아이콘의 접근성 이름은 유지됨을 확인.
- 상세 화면 재생 버튼, 현재 곡의 INFO 버튼, QUEUE 버튼과 삭제 아이콘 동작 확인.
