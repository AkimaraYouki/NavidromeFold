# NaviFold v0.8.0

- 버전 코드 19. debug/QA 빌드 및 단위 테스트 57개 통과. Lint 오류 없음.
- 메인 음질 배지의 고정 300dp 너비 제거. 텍스트에 맞춰 표시하며 최대 240dp로 제한합니다. `FLAC · 96.0 kHz`처럼 포맷/샘플링 레이트를 표시하고 비트레이트는 재생창 상세에 유지합니다. 배지 터치로 재생창을 엽니다.
- NOW PLAYING의 투명 창 배경 대신, 열기 직전 메인 화면을 캡처한 불투명 고정 배경을 사용합니다. 드래그 시 전체 창을 무효화하여 이전 패널 위치를 다시 그립니다. 배경 캡처는 메모리에만 보관하며 파일/외부 서비스로 보내지 않습니다.
- 연결된 삼성 기기에서 QA 앱과 테스트 음원으로 검증했습니다(2448×1848 화면). 2.2초의 느린 드래그 도중 및 종료 화면을 캡처했고, 확인한 화면에서 손잡이/패널 테두리의 누적 잔상은 관찰되지 않았습니다.
- 실제 Navidrome 계정 정보 및 기존 앱 데이터는 검증에 사용하지 않았습니다.

## 동작상 차이

재생창 아래 메인 화면은 창을 열 때의 고정 이미지이며 재생창을 닫으면 실제 메인 화면으로 돌아갑니다. 음악 재생과 재생창 정보 갱신은 계속 동작합니다. 접힌 화면과 모든 방향의 실기 조합을 이번에 모두 시험한 것은 아닙니다.
