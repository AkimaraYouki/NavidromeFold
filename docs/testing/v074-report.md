# NaviFold 0.7.4 버튼·반투명 UI

2026-10-17.

## 변경
- 아이콘 전용 버튼은 빈 텍스트 줄을 배치하지 않는 AppCompatButton으로 변경했습니다. 높이 48dp, 아이콘 24dp 중앙 배치를 사용합니다.
- 앨범·폴더 재생/셔플/대기열/즐겨찾기 버튼 행의 높이를 48dp로 고정하고 일반 텍스트 버튼의 불필요한 글꼴 여백을 제거했습니다. 아이콘 접근성 이름과 툴팁을 유지합니다.
- 부드러운 배경 그라데이션, 반투명 패널, 얇은 밝은 테두리를 탐색 영역·미니 플레이어·설정 카드·버튼·음질 배지·대기열에 적용했습니다. 전체 View의 alpha를 낮춰 글자가 흐려지는 방식은 사용하지 않습니다.
- 설정 > 재생 배경 불투명도: 0~100% 슬라이더, 미리보기, 적용·취소. 기본값 82%. 0%는 배경 레이어가 완전히 투명하고 100%는 불투명합니다.
- 현재 곡 화면의 배경(그라데이션·커버 블러·음영)을 별도 레이어로 묶어 배경만 alpha를 변경합니다. 원본 커버·메타데이터·재생 컨트롤의 alpha는 1로 유지합니다. 뒷 화면의 dim도 배경 값에 맞춰 줄입니다.
- 기존의 검정 펀치홀 링, 기울기 센서 미사용, 인디케이터 뷰 유지 동작은 변경하지 않았습니다.

## 확인
- assembleDebug / assembleQa / testDebugUnitTest / lintDebug 성공. 단위 테스트 27개 통과. lint 오류 0개, 경고 30개.
- 로컬 235개 앨범 fixture에서 앨범 상세 버튼의 실제 측정 높이 48dp 확인. 상세 결과 docs/testing/v074-proof.json.
- 슬라이더를 0/50/100%로 변경·적용한 뒤 값 저장과 실제 재생 배경 alpha 0/0.5/1을 확인. 전경 alpha는 모두 1입니다. 기본값인 82% 화면도 확인했습니다.
- 앨범 목록·상세·불투명도 설정·재생 화면을 에뮬레이터에서 확인했습니다. 원본 앨범 이미지는 테스트용 단색 이미지입니다.

반투명 효과는 앱 내부 레이어 사이에서 적용됩니다. 시스템 전체나 다른 앱의 화면을 흐리게 만드는 기능은 아닙니다. 0%에서는 뒤의 앱 화면이 그대로 보여 글자와 겹칠 수 있으므로 슬라이더로 원하는 값을 선택할 수 있습니다. 기기별 GPU 합성의 체감 성능은 별도 측정하지 않았습니다.

이전 변경 및 검증은 docs/testing/v073-report.md와 v072-report.md를 참고하세요.
