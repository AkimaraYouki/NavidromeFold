# NaviFold 0.7.1 펀치홀·아일랜드 조정

2026-10-17.

## 변경 사항
- 설정 > 펀치홀 · 아일랜드 조정: 링 지름 8~96dp, 아일랜드 너비 140~480dp 슬라이더.
- X/Y 보정은 각각 −3,000~+3,000dp 정수 입력, ±1/±10dp 버튼, 위치 초기화 지원. 조절 중 미리보기, 적용/취소 지원.
- 중앙 카메라 여백을 기준으로 포맷은 왼쪽, 샘플링 레이트는 오른쪽에 표시. 검정 캡슐과 음질 색상 링 유지.
- 인앱 모양은 링 / 아일랜드 / 링+아일랜드 선택. 인앱 전용 / 다른 앱 위 표시 모드는 유지.
- 링과 아일랜드 모두 접힌 화면을 세로 정방향으로 들었을 때만 표시. 화면 회전 잠금 중에도 실제 방향 센서를 사용하여 옆으로 돌림·거꾸로·평평한 상태를 제외. 정방향 허용 각도는 ±25°.
- 펼친 화면과 다른 앱에서의 회전 변경도 동일하게 숨김. 작은 분할 창을 접힌 화면으로 오인하지 않도록 창 폭 대신 전체 디스플레이의 짧은 변 길이를 사용.

## 검증
- assembleDebug / assembleQa / testDebugUnitTest / lintDebug 성공.
- 단위 테스트 27개 통과. lint 오류 0개, 경고 27개.
- Pixel Fold 에뮬레이터 CLOSED/OPENED 상태와 가속도 센서로 접힘 정방향, 회전 잠금 상태의 가로/거꾸로, 평평함, 펼침 조건을 확인. 상세 결과: docs/testing/v071-proof.json.
- 조절창의 슬라이더 저장, X=1234dp 입력, 범위 초과 입력의 적용 거부, 취소 복원, 재진입 후 값 유지, 위치 초기화 확인.
- 다른 앱 위 아일랜드 표시 및 기기를 옆으로 돌렸을 때 숨김 확인.
- QA 전용 수신기와 로컬 데모 서버로 테스트. 배포 debug APK에는 검증 수신기가 포함되지 않음.

## 위치와 기기 제한
접힘 화면 판정은 현재 전체 디스플레이의 짧은 변이 600dp 미만인지로 판단합니다. 특정 기종명이나 힌지 각도에 의존하지 않습니다. 방향 센서가 없거나 방향을 알 수 없으면 표시하지 않습니다. 인앱 카메라 위치는 DisplayCutout을 기준으로 하며 렌즈의 정확한 크기는 사용자가 조절합니다.

외부 오버레이는 전체 화면 좌표와 cutout 위치를 기준으로 배치하고 입력한 X/Y 보정을 더합니다. 보정으로 중앙이 화면을 벗어나면 화면 가장자리로 제한합니다. 캡슐의 일부가 잘릴 수 있습니다. Android가 시스템 상태 표시줄을 오버레이보다 위에 표시하므로, 외부 앱에서는 그 아래에 가려질 수 있습니다. 삼성 실기기의 실제 카메라와 중앙 여백이 정확히 겹치는지는 사용자가 정방향으로 접어서 추가 보정해야 합니다. 오버레이 삭제 여부는 결정하지 않고 기능을 유지했습니다.

음질 표시는 현재 입력 스트림 기준이며 실제 DAC 출력 측정이 아닙니다. 변환 MP3 시간/탐색 및 잠금화면 구현과 이전 검증은 docs/testing/v07-report.md를 참고하세요. 이번 변경은 AI 추천/자동 넘기기 구현을 포함하지 않습니다.
