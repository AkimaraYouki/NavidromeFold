# NaviFold v0.8.2 · UI / 렌더링 정리

버전 코드 21. debug/QA 빌드 성공. 단위 테스트 66개 통과. Lint 오류 0개, 경고 43개.

## UI

- Pretendard Variable v1.3.9를 앱에 포함했습니다. 한글/영문 글리프와 기본 굵기 400, 제목 굵기 600을 사용하며 기기 글자 크기(sp)를 유지합니다.
- 제목·앨범명·목록 항목은 semibold, 아티스트/연도 등 보조 정보는 regular로 구분했습니다. 제목과 보조 정보 사이 간격, 줄 간격, 글자 패딩을 정리했습니다.
- 앨범 표지 라운드와 표지 아래 간격, 설정 카드 패딩/최소 높이를 통일했습니다. 곡 목록은 48dp 표지와 72dp 행으로 정리했습니다.
- 펼친 재생창에서 앨범 표지 옆 정보·컨트롤을 세로 중앙에 맞췄습니다. 접힌 재생창 배치는 유지합니다.
- 빈 큐에서는 하단 미니 플레이어를 숨기고 곡을 넣으면 복원합니다. NOW PLAYING 중 미니 플레이어는 INVISIBLE로 유지합니다.
- 기존 재생창의 고정 배경/전체 창 다시 그리기, 짧은 메인 음질 배지, 장르 유지 정책을 유지합니다.

## 코드 최적화

- GridView의 앨범/일반/곡 행을 세 가지 view type과 holder로 재사용합니다. 스크롤 시 removeAllViews와 하위 View 재생성을 제거했습니다.
- 재사용된 곡 옵션 버튼은 새로 바인딩한 곡을 참조합니다.
- 표지 캐시 적중 시 placeholder로 먼저 바꾸지 않고 즉시 이미지를 사용합니다. 같은 표지가 이미 바인딩되었거나 로딩 중이면 중복 바인딩/요청 대기를 줄입니다.
- 재생 버튼은 아이콘 Drawable을 보관하고 종류가 바뀔 때만 교체합니다. placeholder의 음악 아이콘도 재사용합니다.
- 글꼴 regular/semibold Typeface를 캐시합니다. 인디케이터에서도 같은 폰트를 사용합니다.

## 검증

Pixel Fold 에뮬레이터와 테스트 서버(235개 앨범, 705곡)로 다음을 확인했습니다.

- 앨범/곡 목록 반복 스크롤 후 재사용된 앨범과 곡 옵션이 올바른 대상에 연결됨.
- 접힘/펼침 재생창, 앨범 목록, 곡 목록, 설정 화면 육안 확인.
- 빈 큐에서 미니 플레이어 GONE, 재생 시 VISIBLE, 재생창 열림 중 INVISIBLE, 큐 비우기 후 GONE 확인.
- 한국어 글리프와 가변 굵기 정보 확인. 라이선스 파일을 APK assets/licenses/Pretendard-OFL.txt에 포함.

이번에는 USB 휴대폰 연결이 끊겨 실제 삼성 기기에 설치하지 못했습니다. 실기 미검증 버전이며 APK로 제공됩니다. 성능 향상은 재생성/중복 작업 제거를 코드와 동작으로 확인한 범위이고 FPS/배터리 수치를 측정한 것은 아닙니다.
