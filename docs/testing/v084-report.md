# NaviFold v0.8.4 · 반복 작업 최적화

버전 코드 23. debug/QA 빌드 성공, 단위 테스트 72개 통과. Lint 오류 0개, 경고 41개.

## 변경

- FlowPolicy.Matcher: 장르/음악권/언어/아티스트/장르 계열을 프로필로 계산합니다. 기준 곡은 후보 묶음당 한 번 파싱하며 후보 곡도 장르를 중복 파싱하지 않습니다. 정규식 Pattern을 재사용합니다. 다양하게 모드에서는 제한 프로필 생성 자체를 생략합니다.
- 추천 유사도: 기준 곡과 선호 곡의 메타데이터를 한 번 읽어 Features로 재사용합니다. 후보 곡의 레이블/아티스트/연도/BPM을 비교할 때 같은 JSON과 배열을 반복 해석하지 않습니다. 가중치와 장르 정책을 유지합니다.
- AppSettings.cached: 주기적 인디케이터 작업에서 읽기 전용 설정 스냅샷을 공유합니다. 설정 저장 시 listener가 무효화합니다. 수정 가능한 메인 화면 설정 인스턴스와 분리했으며 Activity를 보관하지 않습니다.
- 숨겨진 인앱 인디케이터의 주기적 갱신을 중단하고 다시 보이면 재시작합니다. 기울기 센서를 추가하지 않았습니다. 표시 조건 계산용 Point를 재사용합니다.
- 큐 팝업: 재생/일시정지/AI 토글만 바뀌면 목록을 재바인딩하지 않습니다. 현재 곡 변경 시 이전/새 현재 행만 갱신합니다. 실제 목록 교체/추가/삭제/이동에서는 구조를 다시 반영하고, 드래그 종료 시 전체를 맞춥니다. SOURCE_UPDATE를 목록 교체로 취급하지 않습니다.
- 메인 화면은 다른 팝업/재생창 뒤에서 포커스가 없을 때 500ms 주기의 UI 갱신을 건너뜁니다. 플레이어 이벤트와 서비스의 재생/통계/추천 처리는 유지합니다.

3. 삼성 기기 QA에서 설정 스냅샷 재사용과 설정 변경 시 즉시 무효화 확인.

6. 메타데이터 유사도 가중치/누락 값/공백·전각 문자 정규화 회귀 검증 포함.

UI 디자인과 음질/데이터 경고/자동 절약 설정의 의미는 변경하지 않았습니다. 실제 ChatGPT 호출과 휴대폰 배터리/FPS 프로파일링은 이번 검증 범위에 포함하지 않았습니다.
