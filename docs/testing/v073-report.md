# NaviFold 0.7.3 인디케이터 안정화

2026-10-17.

## 수정
- 화면을 다시 구성할 때 인디케이터 뷰를 제거·재생성하던 코드를 변경했습니다. Activity의 같은 뷰를 유지하며 컨텐츠만 다시 구성합니다.
- OrientationEventListener 및 센서 등록·해제를 제거했습니다. 기기 기울기나 평평함, 센서의 방향 알 수 없음 상태로 인디케이터를 숨기지 않습니다.
- 표시 조건은 현재 디스플레이의 짧은 변 600dp 미만과 화면 회전값 0입니다. 접힌 세로 화면에서는 기울어져도 유지되며, 펼침 및 화면 자체의 가로/역방향 회전에서는 숨깁니다.
- 조절창과 안내 문구도 기울기 제한이 없는 현재 동작으로 갱신했습니다. 링 크기, 아일랜드 좌표, 오버레이 선택과 기존 설정값은 유지합니다.

## 확인
- assembleDebug / assembleQa / testDebugUnitTest / lintDebug 성공.
- 단위 테스트 27개 통과, lint 오류 0개 및 경고 29개.
- QA 앱에서 4개 탐색 탭을 2회 순회하는 8번의 전환 동안 뷰 identity가 유지되고 detach 이벤트가 0회임을 확인했습니다.
- 현재 곡 시트와 인디케이터 조절 팝업을 열고 닫아도 동일한 뷰가 유지됐습니다.
- 회전 잠금 상태에서 upright, tilted, flat, sideways 센서값을 주어도 접힌 세로 화면 표시 조건이 모두 true임을 확인했습니다. 펼친 화면은 false입니다.
- 상세 증거: docs/testing/v073-proof.json. 진단 수신기와 뷰 관찰 코드는 QA 전용이며 배포 debug APK에는 포함하지 않습니다.

전체 디스플레이 크기로 접힘 화면을 판단하는 기존 방식과 기종별 카메라 좌표 보정은 유지합니다. 위 검증은 에뮬레이터에서 뷰 유지 여부를 확인한 결과이며 삼성 실기기의 모든 전환 애니메이션을 프레임 단위로 측정한 것은 아닙니다.

이전 UI 문구 정리: docs/testing/v072-report.md. 기존 아일랜드 조정: docs/testing/v071-report.md (센서 관련 내용은 이번 버전에서 변경됨).
