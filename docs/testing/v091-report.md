- 앨범·수록곡 사전 분석: 3앨범/60곡 단위, 앨범 메타데이터 반복 전송 감소, 시작·중단·이어서 처리.
- `smart-library.db` 버전 3의 `track_profiles`에 원본 태그와 분리해 저장합니다. 지문 변경·만료에 따른 재분석, 불확실한 추정의 낮은 활용도, 앨범 카드의 GPT 추정 표시.
- 태그 누락이 기존 보완 값을 지우는 문제와 보완 전에 후보를 제외하는 순서 수정.
- 첫 100곡만 가져오던 대체 경로 개선. 전체 곡 페이지 조회·캐시와 제한된 구형 서버 대체 경로.
- 작은 라이브러리의 최근 제외 완화, 현재/예정 곡 중복 방지는 유지하면서 지난 재생 항목 재추천 허용.
- 엄격 모드·명시된 장르/음악권/언어 충돌·비선호 조건은 유지합니다. 원인별 상태와 재시도 대기를 구분합니다.

## 확인하지 않은 범위

실제 ChatGPT 계정의 추론 호출·전체 라이브러리 분석 품질·플랜 사용량은 확인하지 않았습니다. 모델 경로는 테스트 구현을 주입해 결과 검증·캐시 처리를 확인했고, 외부 전송 형식은 기존 계정 연결을 재사용합니다. 사용자의 실제 음악 데이터가 미리 분석 완료된 상태를 뜻하지 않습니다.

휴대폰이 연결되어 있지 않아 이번 버전은 에뮬레이터로 검증했습니다. 대규모 라이브러리의 장시간 분석·배터리 및 앱 강제 종료/계정 변경과 전체 분석 작업의 모든 조합도 미검증입니다. 분위기·활기는 메타데이터와 모델 지식을 바탕으로 한 추정이며 음원 분석 결과나 객관적 확신도 측정이 아닙니다.


## 2026-10-20 · OpenAI DNS 오류 확인

- 사용자 화면의 `UnknownHostException`은 DNS 단계 실패. 현재 실기에서는 재현되지 않음.
- ChatGPT 설정에 명시적으로 실행하는 연결 검사 추가. 앱 기본 네트워크로 공개 GET만 사용하며 인증정보·음악 데이터·모델 요청을 보내지 않음.
- 실제 Next 패키지 업데이트 후 설정 화면에서 검사 실행. VPN 상태에서 `auth.openai.com` HTTP 200, `api.openai.com` HTTP 401 확인. 인증 없는 API 요청의 401은 서버 도달 증거이며 계정 권한 검증은 아님.
- VPN·Private DNS·계정 설정은 변경하지 않음. 로그인이나 추천의 자동 재시도는 추가하지 않음.
- 로그인·분석·검색 오류에서 DNS/timeout/TLS/접속 실패 안내 구분. 기존 처리 가능한 계정·한도 메시지 유지.
- 단위 테스트 125개 통과, Lint 오류 0 / 기존 경고 45, debug APK 빌드·실기 업데이트 성공.
- 최초 실패 시점의 네트워크 원인은 확정하지 못했고 실계정 로그인·유료/플랜 추론 호출은 실행하지 않음.


## 2026-10-20 · 재로그인 등록 정보와 실패 단계

- 0.9.0 및 초기 소스와 비교: 기존 authorize URL과 dynamic 등록 방식은 동일. Next의 저장 공간은 기존 앱과 별도. 이름 수정 가능 화면은 OpenAI의 신규 등록 흐름.
- 최초 콜백에서 받은 발급 client ID를 코드 교환 전에 암호화 저장. `pending_client_id`로만 보관하며 검증된 계정·토큰으로 취급하지 않음. 통신 실패 뒤 새 승인 코드로 재인증할 때 재사용.
- 기존 검증 계정 ID가 우선하며, 재인증 콜백의 client ID 변경을 거부. 동일 검증 계정에만 ID-token/email 힌트 전달. 서명·신원 검증 전 계정 교체 금지 유지.
- 로그인 준비/승인 대기/코드 교환/서명 확인/저장 단계와 안전한 오류 안내를 최근 로그인 상태에 표시. 코드·토큰·서버 응답 본문은 상태에 저장하지 않음.
- 잘못된 로컬 접속의 읽기 timeout 이후에는 승인 대기를 유지. 전체 승인 제한 시간은 3분으로 유지.
- 단위 테스트 133개 통과. 등록 후 교환 실패 재시도, 미검증 등록과 계정 분리, 기존 계정 우선, 다른 등록 ID 거부 등 8개 회귀 검증 추가. Lint 오류 0 / 경고 43. debug 및 QA 빌드 통과. Next 실기 업데이트 완료.
- 사용자 재로그인 결과를 기다리는 상태. 실제 계정 로그인 성공이나 최초 장애 원인이 해결됐다고 확정하지 않음.
