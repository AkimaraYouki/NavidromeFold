# NaviFold v0.8.3

버전 코드 22. debug/QA 빌드 성공. 단위 테스트 69개 통과. Lint 오류 없음.

## 캡처 배경의 앨범 모서리

하드웨어 outline 클리핑에만 의존하던 커버를 RoundedArtwork로 교체했습니다. draw 단계에서 캐시한 Path로 커버 전체를 클리핑하므로 NOW PLAYING의 고정 배경 캡처에서도 같은 둥근 모서리를 유지합니다. 앨범 그리드, 목록 썸네일, 상세 표지와 미니 플레이어에 적용했습니다. 기존의 불투명 고정 창 배경과 드래그 시 전체 창 다시 그리기를 유지합니다.

## 조용한 AI 상태

NOW PLAYING 하단 가장자리에 10sp/낮은 강조도의 상태 한 줄과 2dp indeterminate 진행바를 표시합니다. 추천 진행 중에만 바를 표시하고, 완료/대기 때는 숨깁니다. 상태를 터치하면 최근 8개 이벤트를 시간과 함께 표시합니다. 계정별 scope로 표시를 제한하며, 원시 오류/서버 비밀번호/음원 파일은 로그에 넣지 않습니다. 서비스 종료/오래된 추천 결과에서도 busy 상태를 해제합니다.

## 데이터 편의 기능

설정 → 데이터 · 네트워크:

- 현재 연결, 오늘 앱 전체 수신/송신량, 모바일/요금제 연결 추정량.
- 요금제 연결 경고 ON/OFF. 기본 일일 500 MB, 100/250/500 MB/1/2 GB/없음 선택.
- 경고 기준 도달 시 인앱 안내. 기존 알림 권한이 있으면 별도 데이터 알림도 하루/기준당 한 번 표시합니다. 새 알림 권한을 자동으로 요청하지 않으며, 경고가 재생을 중단하지 않습니다.
- 요금제 연결에서 원본 재생 중이면 메인 화면 및 NOW PLAYING 하단에 MP3 192 kbps를 추천합니다.
- MP3 192 kbps로 설정하는 메뉴.
- 요금제 연결 자동 절약은 기본 OFF. 켜면 요금제 연결에서 새로 준비하는 곡을 MP3 최대 192 kbps로 요청합니다. 이미 준비된 큐/현재 곡은 유지하며 무제한 Wi-Fi에서는 기본 음질 설정을 따릅니다. 설정 화면에서 이 적용 범위를 안내합니다.
- 오늘 앱 집계 초기화.

자체 UID TrafficStats를 5초 간격으로 읽으며 기본적으로 30초 간격 또는 네트워크 전환/화면 종료 시 저장합니다. 다른 앱의 사용량 접근 권한은 사용하지 않습니다. ACCESS_NETWORK_STATE 일반 권한만 추가했습니다.

## 검증

삼성 기기의 별도 QA 앱 + 테스트 서버로 확인:

- 소프트웨어 캔버스에서 SquareImage의 모서리 색은 배경 유지, 중앙은 표지 색으로 렌더링됨.
- AI busy 상태의 진행바 VISIBLE, 완료 후 INVISIBLE, 최근 기록 팝업 확인.
- 요금제 연결을 QA에서 모의해 원본 요청이 MP3/maxBitRate=192로 바뀌는 것을 확인. 무제한 네트워크 조건에서는 원본 유지.
- 실제 테스트 트래픽의 UID 수신/송신량이 집계됨.
- 데이터 설정 및 오늘 사용량 UI 확인.

폴더블 에뮬레이터 펼친 화면에서 앨범 목록이 보일 정도로 패널을 내려 캡처했고, 드래그 도중 둥근 커버 유지 확인. 최종 데이터 추천/AI 상태 배치도 확인했습니다.

## 범위와 한계

모바일/요금제 구분은 샘플 간 네트워크 기준의 추정값입니다. VPN·재부팅·자정·네트워크 전환 시 오차가 있을 수 있으며 통신사 청구량과 다릅니다. 기능을 처음 켠 이전의 과거 사용량은 복구하지 않습니다. 실제 셀룰러 핸드오버와 500 MB 임계값 알림 전송은 이번 테스트에서 발생시키지 않았고, 카운터/임계값/음질 조건은 단위 테스트와 QA 모의 환경으로 검증했습니다. 자동 절약은 이미 만들어진 큐를 재작성하지 않습니다. 서버 트랜스코딩 설정이 필요합니다.
