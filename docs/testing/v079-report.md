# NaviFold v0.7.9 검증 결과

- 버전 코드 18, debug/QA 빌드 성공, APK 서명 검증 성공.
- 단위 테스트 55개 통과. Lint 오류 0개, 경고 42개.
- 폴더블 에뮬레이터에서 235개 앨범/705곡 테스트 서버로 검증했습니다.
- Android Keystore AES-GCM 암호화 저장 확인. 프로세스 강제 종료 후 자동 로그인 확인. 로그아웃 후 재실행 시 연결 해제 유지 확인.
- 재생창의 앨범명 터치 → 실제 앨범/곡 목록 이동 확인.
- ALBUM, SONG, 즐겨찾기 정렬 팝업, 앨범 내부 정렬 확인.
- 다국어 순서, 관사 제외, 누락 날짜 마지막, 디스크/트랙 순서 및 재생 횟수 단위 테스트 통과.
- 접힌 화면에서 재생창 드래그 닫기 및 미니 플레이어 복원 확인. 재생창 하드웨어 강제 레이어와 실시간 RenderEffect 블러를 제거하고 사전 계산한 배경 비트맵을 사용합니다.
- 음질 표시를 별도 우측 정렬 영역에 배치했습니다(최대 300dp, 두 줄). 접힘/펼침 화면 확인.
- 서버 관련 항목을 설정 최상단으로 이동하고 중복 반복/셔플 항목을 제거했습니다.
- 곡 필터/정렬 결과 캐시, 중복 앨범 총수 네트워크 조회 제거, 사용하지 않는 메타데이터 View 생성 제거.

## 확인 범위

실제 서버 비밀번호는 이전 버전에서 보관하지 않았으므로 업데이트 후 최초 한 번 로그인해야 합니다. 이후 자동 로그인합니다. 정렬의 날짜/재생 횟수는 서버가 제공하는 정보를 사용합니다. 화면별 정렬 선택은 실행 중 유지되며 설정값은 기본 정렬입니다.

접힘/펼침 검증은 Pixel Fold 에뮬레이터에서 수행했습니다. 삼성 Fold 8 실기의 드래그 중 잔상 소실 여부는 사용자 확인이 필요합니다. 실제 계정의 비밀번호를 읽거나 시험 로그인하지 않았습니다.
