# NaviFold 0.7.0 구현·검증 기록

2026-10-17. Pixel 폴드형 에뮬레이터와 로컬 Navidrome 호환 검증 서버에서 확인했습니다.

## 반영 사항
- 원본/변환 재생을 구분하고 길이를 알 수 없는 변환 스트림에 서버의 곡 길이를 전달합니다. CBR MP3 탐색을 활성화하여 앱과 MediaSession이 같은 타임라인을 사용합니다. 경과 시간을 임의로 증가시키지 않습니다.
- 현재 재생 화면: 둥근 커버와 시트, 커버 배경 블러·그라데이션, 재생 컨트롤, 현재 스트림과 원본 파일 정보를 구분했습니다. 시스템 글꼴과 Material 벡터 아이콘을 사용합니다.
- 펀치홀 주변: 검정 바탕, 1.6dp 음질 색상 링과 약한 빛. 흰 테두리는 제거했습니다. 기본 링 지름 24dp이며 크기와 X/Y 위치는 600dp 창 폭을 기준으로 각각 저장합니다.
- 인디케이터: 꺼짐 / 인앱 전용 / 다른 앱 사용 중에도 표시. 외부 모드는 시스템 오버레이 권한이 필요하며, 앱이 보이지 않고 재생을 요청한 상태에 검정 캡슐을 표시합니다. 탭하면 곡 정보가 열립니다.
- 잠금화면: 표준 미디어 패널과 커버, 별도의 곡 변경 알림. 알림을 누르면 잠금 상태에서도 곡 정보 카드를 표시합니다. 강제 화면 켜기나 full-screen intent는 사용하지 않습니다.
- 앨범 커버 크기·정렬을 포함한 선택 항목은 설정 팝업에 유지했습니다.

## 검증 결과
- assembleDebug / assembleQa / testDebugUnitTest / lintDebug 성공.
- 단위 테스트 21개 통과. lint 오류 0개, 경고 26개.
- 길이 헤더와 Xing 헤더가 없고 Range를 무시하는 CBR MP3 fixture로 테스트했습니다.
- 192kbps: 67.090 → 70.305초 진행, 90초 탐색 후 90.431초. 길이 120.010초, seekable=true. 일시정지 상태 확인.
- 320kbps: 17.467 → 20.677초 진행, 90초 탐색 후 90.359초. 길이 120.010초, seekable=true. 일시정지 상태 확인.
- 실제 현재 스트림 표시는 MP3 · 48kHz · 192/320kbps. 원본 WAV 정보와 구분했습니다.
- keyguard locked=true 상태에서 곡 변경 알림 활성화와 시스템 미디어 패널/커버 표시를 확인했습니다. 테스트 뒤 에뮬레이터의 기존 잠금 비활성 설정을 복원했습니다.
- 다른 앱 위 검정 캡슐 표시와 탭하여 곡 정보 열기를 확인했습니다.
- 검증용 PlaybackProbe는 qa 빌드에만 포함되며 배포 debug APK에는 포함하지 않습니다. 로컬 fixture 생성에만 ffmpeg를 사용합니다.

## 범위·제한
DisplayCutout은 카메라의 안전 경계 영역을 알려주며 렌즈의 정확한 반지름은 알려주지 않습니다. 기종명으로 좌표를 추정하지 않고 현재 창의 cutout 및 사용자 보정값을 사용합니다. cutout이 없는 UDC 등에서는 인앱 링을 그리지 않으며 외부 캡슐은 화면 중앙을 기준으로 표시합니다. 시스템 상태 표시줄 위로 강제로 그리지 않습니다. 삼성 실기기의 접힘/펼침 카메라 정렬은 사용자 기기에서 추가 확인이 필요합니다.

음질 색상은 사용자가 요청한 앱의 구분 기준입니다. 모든 DAC의 공통 표준이 아닙니다. 현재 디코더 입력 포맷 기준으로 파란색(일반/손실), 노란색(무손실 PCM 88.2kHz 이상), 흰색(실제 DSD), 빨간색(오류)을 표시합니다. 보라색은 검증된 MQA에만 예약했으며 MQA 디코딩 구현은 없습니다. 장치의 실제 DAC 출력·비트퍼펙트·네이티브 DSD를 보증하지 않습니다.

실제 Tailscale 서버의 모든 트랜스코더/VBR 조합을 검증하지 않았습니다. 잠금화면 팝업은 알림 권한·채널·개인정보 설정·제조사 정책의 영향을 받습니다. AI 추천·자동 스킵과 오프라인 다운로드는 아직 미구현입니다. 기존 Java View/configChanges 기반 UI 재구성 구조를 유지했습니다.
