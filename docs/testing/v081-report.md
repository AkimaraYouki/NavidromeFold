# NaviFold v0.8.1 · 추천 흐름 유지

버전 코드 20. debug/QA 빌드 성공. 단위 테스트 66개 통과, Lint 오류 0개.

## 변경

- SMART DJ → 장르 유지: 엄격하게 / 자연스럽게(기본값) / 다양하게.
- 사용자 직접 재생한 곡·앨범을 기준으로 고정합니다. 자동 추천곡으로 이동하거나 추천곡에서 다음 곡을 눌러도 기준이 바뀌지 않습니다. 라이브러리에서 직접 다른 음악을 재생하면 새 기준을 설정합니다.
- 엄격 모드: 정규화한 장르 태그의 교집합 필요. 기준 장르 미상 시 보충하지 않습니다.
- 자연스럽게: Pop/Synth-pop 등 정의된 같은 장르 계열 허용. 기준 장르 미상 시 같은 아티스트만 제한적으로 허용합니다.
- 두 모드에서 J-pop/K-pop/C-pop 등의 명시된 음악권 태그가 바뀌는 것을 차단합니다. 양쪽에 언어 태그가 있고 서로 다르면 제외합니다. 가수 이름·국적·발매 국가로 노래 언어를 추측하지 않습니다.
- 다양하게: 장르·음악권·언어 제한을 해제합니다.
- 후보 선정 전, MusicBrainz 보완 후, ChatGPT/로컬 결과를 큐에 넣기 전에 같은 정책을 적용합니다. 맞는 곡이 없으면 임의로 제한을 완화하지 않습니다.
- ChatGPT에는 고정 기준과 유지 조건, 후보의 언어/음악권 태그를 함께 전달합니다. 기존 요청 간격·한도·오디오 미전송 정책은 유지합니다.
- 설정 변경은 다음 보충부터 적용되며 이미 큐에 들어간 곡이나 직접 넣은 곡은 삭제하지 않습니다.

## 실제 플레이어 검증

삼성 기기의 별도 QA 앱과 90곡의 합성 메타데이터로 로컬 추천 경로를 검증했습니다. 실제 계정 로그인 정보는 사용하지 않았습니다.

1. Pop 기준 → Pop/Synth-pop 10곡 보충, J-pop 제외.
2. 추천곡으로 수동 다음 이동 후 재보충 → 기존 Pop 기준 유지(남은 추천 3곡 + 새 추천 10곡 모두 검사).
3. J-pop 직접 재생 → J-pop 10곡, 새 기준 ID 확인.
4. 엄격 모드의 Classical 기준에 적합한 후보 없음 → 0곡 보충, 흐름에 맞는 곡 없음 표시.
5. 다양하게 → 다른 장르 보충 허용.

단위 테스트에는 장르/음악권 충돌, 언어 충돌, 복수 태그에 숨은 J-pop, 추천곡 기준 이탈 방지, 태그 보존과 누락된 재생 메타데이터가 색인 태그를 덮지 않는 경우를 포함합니다. 실제 ChatGPT 추천 응답은 이번 검증에서 호출하지 않았습니다. 결과에 대한 공통 정책 검사는 양 경로에 적용합니다.

## 메타데이터 한계

언어 태그가 없으면 미상으로 취급합니다. J-pop 음원에 Pop만 있고 언어 정보도 없는 경우에는 정확히 구별할 수 없습니다. MusicBrainz 보완은 기존 앨범 장르·레이블 조회를 사용하며, 앨범 발매 국가를 곡 언어로 사용하지 않습니다. 원음의 분위기·언어를 직접 분석하는 기능은 추가하지 않았습니다.
