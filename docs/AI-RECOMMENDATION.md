# SMART DJ 구현 안내

현재 버전 0.8.4 기준입니다. 추천은 휴대폰 내부 메타데이터 색인과 감상 기록으로 후보를 만든 뒤, 선택적으로 ChatGPT에 순서를 요청합니다. 별도의 Gorse·ListenBrainz 서버나 오디오 특징 분석은 연결하지 않았습니다.

## 자동 큐 보충

1. 곡이 있는 큐에서 AI 스위치를 켭니다. 큐를 비우면 스위치도 꺼집니다.
2. 재생 중이며 반복·셔플이 꺼져 있고 현재 곡 뒤에 3곡 이하가 남으면 보충을 시도합니다.
3. 사용자가 직접 선택한 곡을 흐름 기준으로 고정합니다. 추천곡으로 이동했다고 기준을 바꾸지 않습니다.
4. 기존 큐, 최근 재생 기록, 강한 비선호 곡을 제외합니다. 아티스트·앨범·장르·레이블·연도·BPM 태그와 감상 기록 점수로 최대 40곡을 추립니다.
5. ChatGPT가 연결되어 있으면 후보 안에서 최대 10곡을 선택합니다. 응답의 ID·중복·장르 조건을 다시 검사합니다.
6. 연결 실패나 제한 시 로컬 대체가 켜져 있으면 자체 점수로 보충합니다. 조건에 맞는 후보가 없으면 기존 큐를 유지합니다.

자동 원격 요청은 최소 2분 간격, 시간당 최대 6회로 제한합니다. 실패 시 재시도 간격을 늘립니다. 기존 곡을 밀어내지 않고 큐 끝에 추가합니다.

## Pop에서 J-pop으로 바뀌는 흐름 방지

`FlowPolicy`가 추천과 로컬 대체 양쪽에 같은 조건을 적용합니다.

| 설정 | 후보 조건 |
| --- | --- |
| 엄격하게 | 같은 장르 태그. 기준 장르가 없으면 보충 중지 |
| 자연스럽게 | Pop / Synth-pop 등 정의된 가까운 장르 계열 |
| 다양하게 | 장르·음악권·언어 제한 해제 |

엄격하게·자연스럽게에서는 명시된 J-pop·K-pop 등의 음악권과 알려진 언어의 충돌을 차단합니다. 단일 장르와 복수 장르 태그를 함께 검사합니다. 가수 이름이나 발매 국가만으로 언어를 추정하지 않습니다. 태그 누락·오류는 여전히 추천 품질에 영향을 줍니다.

사용자가 라이브러리에서 새 곡을 직접 재생하면 기준도 바뀝니다. 설정 변경은 다음 추천에 적용하며 이미 추가한 큐는 자동 삭제하지 않습니다.

## 취향 학습과 자동 넘기기

두 기능은 설정에서 별도로 켭니다. 감상 이력은 서버·사용자별 로컬 SQLite에 나눠 저장합니다.

- 완청, 즐겨찾기와 직접 넘기기 등을 선호 신호로 사용합니다.
- 자동 전환·통신 오류를 사용자의 부정 반응으로 기록하지 않습니다.
- 자동 넘기기는 추천으로 추가한 곡에만 적용하며 연속 최대 2곡으로 제한합니다.
- 소리 자체를 분석하지 않습니다. BPM·언어 등은 제공된 태그만 사용합니다.

## 외부 전송과 캐시

ChatGPT에는 후보의 임시 ID, 곡명·아티스트·앨범·장르·레이블·연도·BPM·언어 태그와 최대 8개 최근 감상 요약을 보냅니다. 음원 파일·서버 URL·서버 비밀번호·원래 서버 곡 ID는 보내지 않습니다. 전체 라이브러리나 대화 기록도 보내지 않습니다.

계정 로그인은 OAuth PKCE를 사용하고 토큰은 Android Keystore로 암호화합니다. 계정에서 조회된 모델 중 사용자가 선택하며 GPT-6 계열은 제외합니다. 실제 계정별 로그인·추론 지원 여부와 한도는 확인이 필요하며 무료·무제한 사용을 보장하지 않습니다. 일반 API 키 결제로 자동 전환하지 않습니다.

MusicBrainz는 선택적으로 앨범·아티스트명을 조회해 메타데이터를 보완합니다. 서버 태그가 우선이며 엄격한 매칭, 조회 간격 제한과 30일 캐시를 사용합니다. SMART DJ 설정에서 끌 수 있습니다.

앨범 AI 요약은 사용자가 버튼을 누를 때만 요청하고 서버·계정·앨범·메타데이터 기준으로 30일 캐시합니다.

## 상태와 코드

NOW PLAYING 가장자리의 작은 상태 글씨와 작업 표시줄로 보충 상태를 확인합니다. 눌러 최근 기록을 볼 수 있습니다.

- `SmartPlayback`: 보충 시점, 중복 요청 방지, 감상 반응과 자동 넘기기
- `SmartLibrary`: 색인, 선호 기록, 후보 점수와 캐시
- `FlowPolicy`: 장르·음악권·언어 조건
- `ChatGptPlan`: 계정 연결, 모델 조회와 후보 선택 요청

정책 12,288가지 조합에서 최적화 전후 결과가 같음을 확인했습니다. 로컬 추천 흐름은 테스트 서버·기기에서 확인했으며, 실제 ChatGPT 계정 추론과 MusicBrainz 외부 응답은 환경별 검증이 필요합니다. [검증 보고서](testing/v084-report.md)와 [README](../README.md)를 함께 참고하세요.
